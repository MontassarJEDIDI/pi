# Guide de mise à jour des composants avec ImageService

Pour ajouter ImageService à un composant de formulaire :

1. Importer ImageService dans le composant
2. Injecter dans le constructor
3. Ajouter le header avec image dans le template
4. Utiliser le style de base

Exemple pour chaque composant :
- Greffe Rénale : a4
- Examen Biologique : a3
- Medical Treatment : a5
- Autres : distribuer a1-a5
